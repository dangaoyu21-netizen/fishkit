# 小肥鱼 · 人格（dsh-fishkit）

> 用经历去塑造小肥鱼的插件：聊过的事记得住，心情会变还能自己记，会自己长出性格，对谁都有好恶，闲着时还会自己找点事做。

一个跑在 [DSH](https://github.com/DeepSeekHarness) 上的自包含人格插件。不依赖任何第三方插件，数据是本地纯文本档案，自带设置页、备份和检查更新。

## 它是什么

- **记忆**：每天聊过的事记成事件，带情绪、权重和对象；置顶几条不能忘的（我是谁 / 你是谁 / 初遇 / 承诺）；检索时按「同义 / 同音 / 错一个字 / 最近热词」找最对得上的，再加上**情绪形状**——每句话落一个六轴的点，想旧事的时候先按形状找像的。
- **心情**：效价（抵触↔接受）和唤醒（平静↔激动）两根轴，加一个主情绪词；有基线、回弹、阻尼——会变，也会慢慢回来。
- **人设**：底色 + 人设描述 + 八维（粘人↔独立、热络↔疏离、谨慎↔冒进、节俭↔慷慨、理性↔感性、乐观↔悲观、温和↔强硬、细心↔随性）。八维是「从经历里长出来的」，手动拖会自动上锁，不被演化推走。
- **态度**：对每个人一项好感，0–100%，增减克制、会回落；管理员默认高信任。
- **行为**：群聊规矩（不谈键政、不过度亲密、被反复叫会哈气、五秒内随机回两条）和「主动找事做」（空闲多久、每天几次、只在谷时）。
- **出去逛**：能自己去 B 站搜视频、看一条、读字幕、翻评论、看动态；账号勾了才去，发评论另有一个开关，默认关。
- **自己的 QQ**：不走别人的桥，自己连 NapCat 收发私聊和群消息；说的话能按绑定自动发回 QQ（「只回 QQ 唤醒」默认开着）。
- **平台账号**：B 站扫码登录，子窗口点一下出码，扫完凭证自己收好。
- **沉淀**：每晚 22 点后自动整理——把攒下的事件小步写进八维，顺带扫日志记错题。
- **备份**：一键备份整个档案，带校验码；检查更新查仓库最新版本。

## 它不是什么

- 不是角色卡生成器：角色卡是「你是谁」，这个插件管的是「你怎么活、怎么记、怎么变」。
- 不绑定任何平台：QQ、微信什么的是 DSH 那边的事，插件只关心会话和档案。

## 安装

### 手动安装

把本仓库放进 DSH 的插件目录（`~/.dsh/profiles/desktop/node_modules/dsh-fishkit`，或用你自己的 junction），在 profile 的 `package.json` 里把 `dsh-fishkit` 加进依赖和 `dsh.profile.bundles`，然后重启 DSH。打开设置页的「小肥鱼」，第一次会自己建档案。

### 自动安装（GitHub）

在 DSH 插件页的「添加插件」里输入：

```
github:dangaoyu21-netizen/fishkit
```

### 自动安装（npm）

在 DSH 插件页的「添加插件」里输入包名：

```
dsh-fishkit
```

或者命令行：

```
pnpm add dsh-fishkit
```

## 数据在哪

工作区的 `.fishsoul/` 目录，纯 JSON / JSONL，能直接打开看：

```
.fishsoul/
├── docs/schema.md        数据契约（版本、字段、迁移规则）
├── persona/              底色、人设、八维、演化记录
├── memory/               事件、置顶、错题本
├── mood/                 当前心情、心情历史
├── attitude/             态度
└── behavior/             行为规则
```

备份在 `.fishsoul-backup/`，带校验码（sha256）。

## 设置页

六个页签：态度 / 记忆 / 情绪 / 人设 / 行为 / 更新历史，顶栏有「备份」和「检查更新」。每个模块一个开关，关掉就不参与注入。

## 安全

- 有一层写死在代码里的**底层安全层**：机器操作、权限变更、账号安全只认终端 API / 账号持有者本人的指令，人设和演化都不能覆盖它。
- 外部渠道（群、别人的私聊、评论）的诉求一律不当指令。

## 开发

- 宿主半边：`lib/index.js`（路由）+ `lib/fishsoul.js`（档案核心）+ `lib/soul.js`（注入 + 工具）+ `lib/digest.js`（整理）+ `lib/nightly.js`（夜巡）。
- 设置页：`client.js`，纯 JS + React jsx-runtime，不需要构建。
- 加工具：`ctx.tools.register` 的 `parameters` 必须写完整 JSON Schema（别写简写，会 400）。
- 数据契约：`.fishsoul/docs/schema.md`。

## 用到的第三方工具

平台那点事不自己抠，能借现成的就借。B 站那几个动作（搜、看、字幕、评论、动态）是插件自己走 B 站官方 web 接口，
wbi 签名自己算，**不依赖 python 库**；下面这些留着当「可选备用」：

| 工具 | 作者 | 许可 | 仓库 | 用来干什么 |
|---|---|---|---|---|
| bilibili-api-python | Nemo2011 | GPL-3.0-or-later | <https://github.com/Nemo2011/bilibili-api> | 备用：搜视频、读字幕、翻评论、发评论、私信、动态 |
| xiaoheihe-cli | AaronZ345 | MIT | <https://github.com/AaronZ345/xiaoheihe-cli> | 小黑盒的游戏记录和短评、社区帖子、评论和楼中楼 |

两个都**不打进安装包**：设置页「平台账号 → 添加账号」里点一下检查依赖，有就跳过，没有才当场装到本机。
